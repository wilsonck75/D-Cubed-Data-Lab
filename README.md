# D³ Data Lab

Notebooks and data for the projects on [wilsonck75.github.io](https://wilsonck75.github.io).

## Projects

| Folder | What it covers |
| --- | --- |
| `macro-factor-model-em` | How emerging-market equity indices respond to global macro factors, using PCA and linear regression. |
| `Prime-Numbers` | Prime search, timing comparisons, and summary charts. |
| `squash-project` | Session-level behavior and revenue for a sports organization: segmentation, RFM, and clustering. |

Each folder has its own README. In `squash-project` and `macro-factor-model-em`, start with the `01_` notebook.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
